# WBGT 導入時の判断

作成日: 2026-09-12  
根拠: [GitHub Issue #34](https://github.com/H-Inagawa/pacecast/issues/34)

| 項目 | 判断 | 理由 |
| --- | --- | --- |
| 気象距離 | 推定 WBGT の絶対差だけ | Issue での確認。気温差は残さない |
| 式 | 小野・登内 (2014) / 環境省実況推定 | アメダスに黒球が無い。環境省と同じ式なら後から公式値とも比べられる |
| 地点 | 設定のアメダスプルダウン。未設定時は東京 44132。テスト用既存設定は練馬 44071 | #11。走行追加と予報でも地点を選べる |
| 過去の風・日射 | Open-Meteo 再解析を主にする | アメダス map JSON は数日しか残らない。練馬に全天日射の観測も無い |
| 既存走で取れない行 | WBGT なしのまま予測除外 | Issue での確認。半数以上付かなければ別案を検討する |
| 一覧の WBGT 表示 | 予測の根拠表と同じ `21.0℃ / 60% / WBGT 19.9`。ヘッダに説明アイコン | Issue #34 追記。保存と予測が安定したため入れる |
| 根拠表の気象距離 | 予測対象 WBGT との符号付き差（高いと `+`、低いと `-`） | 重み付けは絶対差のまま。表示だけ符号を付ける |
| 手動 CSV・気象画面 | 廃止 | #13。自動取得が主経路になったため |
| 分析画面 | 仮に WBGT × ペースの散布図だけ。ホームから遷移 | #12。詳細な分析・配置は後回し |
| アプリ説明 | ホームの「PaceCastとは？」モーダル。出典は出す。本体ライセンスは未定と書く | #36。LICENSE の決定は開発者 |
| ドロワー | ヘッダ左。今の画面は強調してリンクにしない | #33 |
