# 開発計画

作成日: 2026-09-06

## 推奨ステップ

構想どおり、仕様を先に残してから実装する。

1. 要求の整理と不足要件の洗い出し → `docs/01_requirements/`
2. 構成の決定 → `docs/02_architecture/system-architecture.md`
3. DB 設計 → `docs/03_database/database-design.md`
4. MVP 実装（気象取り込み → 記録 CRUD → 紐付け → 予測 → UI）
5. 自動テスト（パース・紐付け・予測）
6. ブラウザでの主要フロー確認

## このあとの段階（MVP 後）

1. 気温・湿度とペースの散布図、推移グラフ
2. 過去心拍から強度ゾーンを個人化
3. 気象の定期取得
4. 回帰または簡易 ML との精度比較
5. 複数ランナー・外部サービス連携

## 今後作成・更新すべきドキュメント

- 本ディレクトリの各資料（判断が変わったら更新）
- `AGENTS.md`（実装時の現行仕様）
- 予測手法を変えたときのアルゴリズムメモ（`docs/02_architecture/` に追記）
