# 走行強度を含む予測（v4）

更新日: 2026-09-13  
根拠: `docs/05_improvements/settings-and-heart-rate.md`、[#43](https://github.com/H-Inagawa/pacecast/issues/43)

## 1. 目的

指定した気象条件で、設定画面の強度別心拍数（目標 bpm）のときに出せるペースを見積もる。

## 2. 強度の定義

目標心拍はプロフィールに保存する。未入力なら最大心拍数 × 下表の割合（四捨五入）を提案値とする。個別上書きもできる。

| キー | 表示 | 割合 |
| --- | --- | --- |
| low | 低強度（60〜70%） | 65% |
| medium | 中強度（70〜80%） | 75% |
| high | 高強度（80〜90%） | 85% |
| race_5k | 5km（90〜100%） | 95% / 5.0 km |
| race_10k | 10km（90〜95%） | 92% / 10.0 km |
| race_half | ハーフマラソン（85〜92%） | 88% / 21.0975 km |
| race_full | フルマラソン（75〜88%） | 80% / 42.195 km |

最大心拍数の年齢式は `220 - 満年齢`。満年齢は誕生日から今日までの年数を切り捨てる。

bpm の丸めは四捨五入（`round`）する。

## 3. アルゴリズム

1. 気象が付き、推定 WBGT がある過去走を対象にする
2. 心拍付きが 6 件以上なら心拍を説明変数に入れる。未満なら WBGT と距離だけ
3. 目的変数はペース（km/h）。画面と RMSE は秒/km
4. 直近ほど重い指数減衰 `exp(-0.0075 × 経過日数)` を重みにした最小二乗
5. 項は件数に応じて、定数 → 主効果（WBGT / 距離 / 心拍）→ 交差 → 2 次。変数は標準化してから使う。解けなければ高次から落とす
6. 予想タイム = 予想ペース（秒/km）× 指定距離
7. RMSE は学習残差の重み付き平方根（秒/km）。R² は重み付き。信頼度は R² が 0.70 以上で高、0.40 以上で中、未満は低
8. 画面の予測結果には予想平均心拍を出さない。目標 bpm は式の心拍項に使う（API は互換のため `predicted_heart_rate` に目標 bpm を返す）
9. 根拠表の気象距離は、過去走 WBGT − 予測対象 WBGT（高いと `+`、低いと `-`）。表の並びは新しい走から最大 8 件
10. 結果に WBGT / 心拍 / 距離とペースの関係グラフを付ける。曲線は他の変数を予測条件で固定した式。分析画面（#12）の散布図とは別
11. 記録の距離・心拍から大きく外れた条件では、式が外挿になりペースが大きくずれることがある。今は警告も補正もしない（[#44](https://github.com/H-Inagawa/pacecast/issues/44)）

## 4. 記録行の色分け

設定の `row_color_mode` で、心拍 / 気象（WBGT） / しない、を選ぶ。同時には塗らない。

心拍のときは、最大心拍があり設定が心拍のときだけ塗る。心拍未入力の行は白。

| 条件 | クラス |
| --- | --- |
| 平均心拍 / 最大心拍 < 0.70 | `low`（薄い青） |
| 0.70 以上 0.80 未満 | `medium`（薄い黄） |
| 0.80 以上 | `high`（薄い赤） |
