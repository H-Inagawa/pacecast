# 初期バージョン（MVP）の範囲

## ゴール

次がローカルのブラウザで一通りできる状態を MVP とする。

1. 走行を保存すると、近い時刻の気象が自動で付く
2. ランニング記録を登録・一覧・編集・削除できる
3. 気温・湿度、または予報日時を指定して、ペース・タイムの予測が見られる

## 含めるもの

- 過去気象の自動取得（アメダス map JSON と Open-Meteo 再解析）
- 走行記録の作成・一覧・編集・削除
- 開始日時による気象の自動紐付け
- 類似気象に基づく統計予測
- Open-Meteo を使った日時指定予測
- 予測根拠（使った過去走と信頼度）の表示

## 含めないもの

- 手動の気象 CSV 取り込みと気象データ画面
- ユーザー登録・ログイン
- グラフ描画
- 学習済み ML モデル
- 外部ランニングサービス連携
- 本番向けデプロイ設定

## 成功の目安

- 記録を保存すると、許容時間内の気象が付く
- 記録 0 件でも画面が壊れず、予測不可と明示される
- 記録が数件あれば予測値が返り、根拠件数が見える
- 自動テストで紐付け、予測の基本ケースが保証される
