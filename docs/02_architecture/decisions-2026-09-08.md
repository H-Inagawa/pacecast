# 予想平均心拍を結果に出さない判断

作成日: 2026-09-08  
根拠: [GitHub Issue #4](https://github.com/H-Inagawa/pacecast/issues/4)

## 判断

予測結果に予想平均心拍は出さない。画面に出すのはペースとタイム。

心拍は次の用途に残す。

- 記録の平均心拍数（任意項目）
- 予測時の走行強度（設定の目標 bpm）
- 類似走の重み付け（心拍距離）

## 理由

API の `predicted_heart_rate` は、過去走から推定した値ではなく、選んだ強度の目標 bpm そのものだった。結果カードに出すと「予測した平均心拍」に見えるため、出さない。

初期構想・改善要望の原文（予想平均心拍数）は残す。現行仕様は `AGENTS.md` と本ファイルを正とする。
