# 改善実装時の判断

作成日: 2026-09-06  
根拠: `docs/05_improvements/second-request.md`

要望 7 節に沿い、独自判断した項目を残す。後から変えてよい。

| 項目 | 判断 | 理由 |
| --- | --- | --- |
| 走行時間の「時」 | 0〜23 | 一般的なロング走をカバーし、2桁表示に収まる |
| 予測の気象指定 | 既存の「手動入力」と「予報日時」を維持 | 6.1 の「登録済み気象から選択」は制御の例示。新方式は追加しない |
| 未選択フォーム | 非表示ではなく disabled | 要望どおり、今どの方式かを残して見せる |
| 気象距離の UI | クリック／タップで開くポップオーバー。デスクトップはホバーでも開く | モーダルより軽く、スマホでも使える |
| グローバルナビ | ロゴ（ホーム）のみ。各画面に「ホームへ戻る」 | メニュー依存を減らしつつ、画面が増えても迷わない |
| ヘッダ | 画面上部に sticky 固定 | スクロール中もロゴ・ユーザー名・設定へ戻れる |
| 記録の追加・編集 | 半透明モーダル。削除は確認ダイアログ | 一覧から離れずに入力・修正できるようにする |
| ホームの導線 | 大きなボタンは「走行記録」と「予測」。最近の走行は出さない | 記録の操作は走行記録画面に集約する |
| 下部操作 | 記録・予測・設定・気象でホーム戻りを画面下に固定。主要操作とホーム戻りは高さ同じ・横幅 3:1 で全幅 | スクロール中でも押せるようにする |
| 距離表示 | 小数第2位 | 短いジョグとレース距離を見分けやすくする |
| 強度の個人化 | 初期は固定 bpm。記録への強度列は持たない | 件数が少ない。予測パラメータとしてだけ使う |
