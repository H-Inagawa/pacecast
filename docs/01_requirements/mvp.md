# 初期バージョン（MVP）の範囲

## ゴール

次がローカルのブラウザで一通りできる状態を MVP とする。

1. 同梱の気象 CSV を取り込み、件数と期間を確認できる
2. ランニング記録を登録すると、近い時刻の気象が付く
3. 気温・湿度、または予報日時を指定して、ペース・タイム・心拍の予測が見られる

## 含めるもの

- 気象 CSV インポート（CLI 相当の処理をアプリ起動時と画面から実行）
- 走行記録の作成・一覧・編集・削除
- 開始日時による気象の自動紐付け
- 類似気象に基づく統計予測
- Open-Meteo を使った日時指定予測
- 予測根拠（使った過去走と信頼度）の表示

## 含めないもの

- ユーザー登録・ログイン
- グラフ描画
- 学習済み ML モデル
- 外部ランニングサービス連携
- 本番向けデプロイ設定

## 成功の目安

- 気象データが約1年分（おおよそ 8,700 時間超）取り込める
- 記録 0 件でも画面が壊れず、予測不可と明示される
- 記録が数件あれば予測値が返り、根拠件数が見える
- 自動テストで CSV パース、紐付け、予測の基本ケースが保証される
