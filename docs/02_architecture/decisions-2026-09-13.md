# 予測を式モデルにした判断

作成日: 2026-09-13  
根拠: [GitHub Issue #43](https://github.com/H-Inagawa/pacecast/issues/43)

| 項目 | 判断 | 理由 |
| --- | --- | --- |
| 現行の加重平均 | やめて式モデルにする | Issue での確認 |
| 表示単位 | 秒/km のまま | 画面の一貫。計算だけ km/h を使ってよい |
| 説明変数 | WBGT・距離・心拍。交差と 2 次は件数に応じて | 変数同士の相互作用を可能な限り見る |
| 直近 | 指数減衰の重み付き最小二乗（λ=0.0075 / 日） | 壁打ちの案。30 日で約 0.80 |
| 妥当性 | RMSE を誤差の目安、R² を信頼度 | Issue での確認。信頼度ラベルは R² 0.70 / 0.40 |
| 説明 | 予測タイトル横の「予測の見方」モーダル | 方法と基準を同じ画面で見せる |
| 関係グラフ | 予測結果に WBGT / 心拍 / 距離 × ペース | #12 の分析画面は別。こちらは今回の式の説明 |
| 心拍が少ないとき | 6 件未満なら心拍項なし | 交差・2 次を無理に当てない |
| 記録から外れた距離・心拍 | 今は直さない | 2 次・交差が外挿で大きく外れることがある。改善は [#44](https://github.com/H-Inagawa/pacecast/issues/44) |
