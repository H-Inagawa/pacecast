# 走行強度を含む予測（v3）

更新日: 2026-09-06  
根拠: `docs/05_improvements/settings-and-heart-rate.md`

## 1. 目的

指定した気象条件で、設定画面の強度別心拍数（目標 bpm）のときに出せるペースを見積もる。

## 2. 強度の定義

目標心拍はプロフィールに保存する。未入力なら最大心拍数 × 下表の割合（四捨五入）を提案値とする。個別上書きもできる。

| キー | 表示 | 割合 |
| --- | --- | --- |
| low | 低強度（60〜70%） | 65% |
| medium | 中強度（70〜80%） | 75% |
| high | 高強度（80〜90%） | 85% |
| race_5k | 5km（90〜100%） | 95% / 5.0 km |
| race_10k | 10km（90〜95%） | 92% / 10.0 km |
| race_half | ハーフマラソン（85〜92%） | 88% / 21.0975 km |
| race_full | フルマラソン（75〜88%） | 80% / 42.195 km |

最大心拍数の年齢式は `220 - 満年齢`。満年齢は誕生日から今日までの年数を切り捨てる。

bpm の丸めは四捨五入（`round`）する。

## 3. アルゴリズム

1. 気象が付き、推定 WBGT がある過去走を対象にする
2. 気象距離（重み付け）= `|推定WBGT差|`。根拠表の表示は過去走 WBGT − 予測対象 WBGT（高いと `+`、低いと `-`）
3. 目標心拍があるとき、心拍距離 = `|記録の平均心拍 - 目標心拍| / 10`。心拍が無い記録は距離 3 のペナルティ
4. 目標心拍が無いときは気象距離のみ
5. 重み = `1 / (合成距離 + 0.25)` の加重平均でペースを求める
6. 予想タイム = 予想ペース × 指定距離
7. 画面の予測結果には予想平均心拍を出さない。目標 bpm は類似走の重み付けに使う（API は互換のため `predicted_heart_rate` に目標 bpm を返す）

## 4. 記録行の色分け

設定の `row_color_mode` で、心拍 / 気象（WBGT） / しない、を選ぶ。同時には塗らない。

心拍のときは、最大心拍があり設定が心拍のときだけ塗る。心拍未入力の行は白。

| 条件 | クラス |
| --- | --- |
| 平均心拍 / 最大心拍 < 0.70 | `low`（薄い青） |
| 0.70 以上 0.80 未満 | `medium`（薄い黄） |
| 0.80 以上 | `high`（薄い赤） |
