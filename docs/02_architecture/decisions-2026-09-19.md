# 長時間走の気象を2点平均にした判断

作成日: 2026-09-19  
根拠: [GitHub Issue #48](https://github.com/H-Inagawa/pacecast/issues/48)

| 項目 | 判断 | 理由 |
| --- | --- | --- |
| 平均する量 | 気温・湿度・風・日射。推定 WBGT は平均した入力から付け直す | 観測の入力を平均してから式を通す方が、WBGT 同士を平均するより式と揃う |
| 保存 | 実況の1時間値はそのまま。走に開始 FK と終了 FK（`weather_end_observation_id`）を持つ | 共有の気象行を上書きしない。合成行は `(observed_at, station_id)` とぶつかる |
| 短い走 | 1時間以下、または開始と終了が隣の1時間値なら従来の1点 | 8時台の1時間走は朝の1点のまま。5時間走は 8時と13時を平均する |
| 取れないとき | 開始が無ければ未関連。終了だけ無いときは開始の1点 | 未関連・WBGT 無しの現行ルールを壊さない |
| 全時間値平均 | 今はしない | Issue が認める負荷回避。必要になったら見直す |
