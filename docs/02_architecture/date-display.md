# 日時表示の共通規則

作成日: 2026-09-08  
根拠: [GitHub Issue #6](https://github.com/H-Inagawa/pacecast/issues/6)

## 規則

画面に出す日時は、画面を問わず次の形式とする。

`YYYY-MM-DD HH:mm`（例: `2026-09-05 07:00`）

- 区切りはハイフンとスペース。スラッシュは使わない
- 時刻は 24 時間制（走行時間の時が 0〜23 であることと揃える）
- 走行記録一覧・気象データの期間・時刻・予測の予報時刻・予測根拠で同じ整形（`formatDateTime`）を使う

## 入力欄

カレンダーで選ぶ欄は HTML の `date` / `datetime-local` を使う。

- 走行日時、予報日時 … `datetime-local`
- 誕生日、気象の「表示する日」 … `date`

これらの見た目はブラウザ／OS のロケールに従う（日本語環境ではスラッシュ区切りになりうる）。一覧の表示規則とは分け、入力欄のスラッシュは許容する。
