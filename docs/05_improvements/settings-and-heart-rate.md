# 設定画面と最大心拍数・強度別心拍

作成日: 2026-09-06  
更新日: 2026-09-06  
種別: 改善要望（実装中。確認事項は 7 節で確定）

現行の固定強度（低125 / 中145 / 高165 / レース175）を、ユーザー設定の最大心拍数から算出する値へ置き換える。あわせて設定画面と、予測・走行記録表示の連動を追加する。

---

## 1. 設定画面

単一ユーザーのプロフィールを入力・保存できる設定画面を新設する。

入力項目は次のとおり。

| 項目 | 内容 |
| --- | --- |
| ユーザー名 | 表示用の名前 |
| 誕生日 | 年齢と最大心拍数の再計算に使う |
| 最大心拍数 | 強度別心拍とゾーン色分けの基準 |
| 強度別心拍数 | 最大心拍数から算出して表示する（詳細は 3 節） |

画面への導線は、現行どおりグローバルナビを増やしすぎない前提で、ホームから辿れる必要最小限の入口を設ける。

---

## 2. 誕生日変更時の再計算

誕生日を変更したときは、次の確認を出す。

> 最大心拍数を変更しますか？

- **OK**: 最大心拍数を `220 - 年齢` で再計算し、強度別心拍数もそれに合わせて再計算する
- **キャンセル**: 誕生日だけ更新し、最大心拍数と強度別心拍数は変えない

年齢は、保存時点の日付と誕生日から満年齢（年単位の切り捨て）とする想定。端数の扱いは実装時に `docs/02_architecture/` へ残す。

最大心拍数は誕生日経由以外でも、設定画面から直接入力できる。

---

## 3. 強度別心拍数の表示と計算

基準は最大心拍数。表示用の代表値は各ゾーンの中央付近（指定の百分率）とする。

| 表示 | ゾーンの目安 | 表示する心拍 |
| --- | --- | --- |
| 低強度（60〜70%） | 有酸素の余裕走 | 最大心拍数 × 65% |
| 中強度（70〜80%） | テンポ走 | 最大心拍数 × 75% |
| 高強度（80〜90%） | 速い持続走 | 最大心拍数 × 85% |
| レースペース | 下記を折りたたみ | 「開く」で展開 |

レースペースは初期状態では閉じ、「開く」で次を出す。

| 表示 | ゾーンの目安 | 表示する心拍 |
| --- | --- | --- |
| 5km（90〜100%） | 最大心拍数 × 95% |
| 10km（90〜95%） | 最大心拍数 × 92% |
| ハーフマラソン（85〜92%） | 最大心拍数 × 88% |
| フルマラソン（75〜88%） | 最大心拍数 × 80% |

最大心拍数が変わったとき（手入力または誕生日からの再計算）は、上表をすべて再計算する。

百分率から bpm にするときの丸め（四捨五入など）は実装時に決めて文書化する。

---

## 4. パフォーマンス予測

予測時の目標心拍は、現行の固定値ではなく、設定画面の強度別心拍数を使う。

予測アルゴリズム自体（気象距離 + 心拍距離の加重平均）は維持し、目標 bpm の出どころだけを設定値へ切り替える。

### 4.1 距離の指定

次の 2 方式をラジオなどで切り替え、選んでいない側は無効化する（非表示にはしない）。

1. **予測したい距離**  
   これまでどおり km を数値入力する。  
   走行強度は低強度 / 中強度 / 高強度を選び、それぞれの代表心拍（65% / 75% / 85%）で予測する。

2. **レース**  
   5km / 10km / ハーフマラソン / フル のラジオボタン。  
   選んだ種目の距離を予測距離とし、対応するレースペース心拍で計算する。

| レース | 使う距離（想定） | 使う心拍 |
| --- | --- | --- |
| 5km | 5.0 km | 最大心拍数 × 95% |
| 10km | 10.0 km | 最大心拍数 × 92% |
| ハーフマラソン | 21.0975 km | 最大心拍数 × 88% |
| フルマラソン | 42.195 km | 最大心拍数 × 80% |

レースを選んでいるときは、通常の低・中・高強度ではなく、その種目のレースペースで計算する。

## 5. 走行記録の色分け

走行記録一覧（月別表示）で、その記録の平均心拍数を最大心拍数に対する割合でゾーン判定し、行の背景色を変える。

| 条件 | ゾーン | 行の色 |
| --- | --- | --- |
| 平均心拍 < 最大心拍の 70% | 低強度 | 薄い青 |
| 最大心拍の 70% 以上 80% 未満 | 中強度 | 薄い黄 |
| 平均心拍 ≥ 最大心拍の 80% | 高強度 | 薄い赤 |

境界は次で扱う。

- 70% ちょうど → 中強度（黄）
- 80% ちょうど → 高強度（赤）

平均心拍が未入力の行、または最大心拍が未設定のときは色分けせず白表示する。

色分けのオン／オフは設定画面で選ぶ。最大心拍が未入力のときは「しない」固定。

走行記録一覧にも同じ色分けを適用する。

## 6. 既存機能への影響

| 対象 | 影響 |
| --- | --- |
| DB | 単一ユーザーのプロフィール（名前・誕生日・最大心拍）が新たに必要。強度別心拍は最大心拍から都度計算すれば列を増やさなくてもよい |
| 予測 API | 固定の 125/145/165/175 をやめ、プロフィールの最大心拍から目標 bpm を決める。レース種目の指定を追加する |
| 走行記録 API | 色分け用に、サーバがゾーンを返すか、フロントが最大心拍を見て判定する |
| `pacecast/services/intensity.py` | 固定プリセットから、設定値ベースの算出へ拡張する |
| 画面 | 設定画面の新設。予測画面の距離指定。記録一覧の行色 |

走行記録そのものに強度タグは持たない（平均心拍と最大心拍から都度判定する）。

---

## 7. 確定した確認事項

1. **強度別心拍は個別上書きできる。** 最大心拍を変えたときは「強度別心拍数を変更しますか？」を確認する。誕生日変更で最大心拍を再計算する場合は、強度別も合わせて再計算する。
2. **最大心拍未設定時は色分けしない（白）。** 色分け可否は設定で選べる。最大心拍が空なら「しない」固定。予測は、保存済みの強度別心拍があればそれを使い、無ければ気象のみでペースを出す。
3. **ハーフ 21.0975 km / フル 42.195 km。**
4. **走行記録一覧も同じ色分け。**
5. **ユーザー名**は設定に保存し、入力があれば画面上部ヘッダー中央に出す。
