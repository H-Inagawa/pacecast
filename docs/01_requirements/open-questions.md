# 未決事項・検討事項

初期構想時点で不足している要件と、今後具体化が必要な事項。MVP では仮決めして先に進める。

## MVP で仮決めしたもの

| 項目 | 仮決め | 見直し時期 |
| --- | --- | --- |
| 利用者 | 単一ランナー、認証なし | 複数ランナー対応時 |
| 地点 | 設定のアメダス地点（未設定時は東京 44132）。走・予報でも上書き可 | 旅行先の最寄り自動選択 |
| 紐付け時刻 | 走行開始時刻の最近傍1時間値。同距離なら早い方 | 長距離走の評価時 |
| 長時間走の気象 | 開始時刻の1点のみ使う | 分割平均や経過気象を入れるとき |
| 走行強度 | 予測時の固定 bpm（低125 / 中145 / 高165 / レース175）。記録には強度列を持たない | 過去心拍の分位で個人化するとき |
| 予測手法 | 推定 WBGT の近さによる加重平均 | データ蓄積後に回帰や ML を検討 |
| 予報ソース | Open-Meteo（キー不要） | 公式 API や複数地点が必要になったとき |
| 距離の扱い | 予測時に距離を指定し、ペース×距離でタイムを出す | 距離帯別モデルを入れるとき |
| コース・標高 | 考慮しない | GPS 連携時 |

## まだ決めていないこと

- トレッドミルと屋外を分けるか
- 「全力走」と「余裕走」を予測対象からどう除外／分けるか
- 降水など、WBGT 以外の気象要素をいつ入れるか
- 予測結果をどの期間・どの距離帯まで信頼するかの定量基準
- データのバックアップ方針
- デプロイ先（当面はローカル想定）

## 構想にあって初期実装に含めない理由

| 構想の項目 | 扱い | 理由 |
| --- | --- | --- |
| 推移グラフ・相関分析画面 | 将来 | 記録と予測の循環を先に成立させる |
| 機械学習モデル | 将来 | 件数が少ない段階では過学習しやすい |
| 複数ランナー | 将来 | 個人利用で学習サイクルを回す |
| GPS / Garmin 連携 | 将来 | 手入力でデータ項目を確定してから |
