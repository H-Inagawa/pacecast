# 画面構成の追加要望

作成日: 2026-09-06  
根拠: 操作後の追加要望

---

## 1. ヘッダの固定

画面上部のヘッダ（ロゴ・ユーザー名・設定）は、本文をスクロールしても常に見えるように固定する。

## 2. 記録の追加・編集はモーダル

「記録を追加」と「編集」は別画面へ遷移せず、半透明のモーダルで入力する。

- 背景の画面は薄く見える
- キャンセル、背景クリック、Escape で閉じる
- 保存後は開いていた画面を更新する
- 削除時は「記録を削除してよろしいですか？」で確認する

## 2.1 ホームの導線

ホームの大きなボタンは「走行記録」と「パフォーマンスを予測」。
小さめの「PaceCastとは？」は説明モーダル、「分析結果を見る」は分析画面へ遷移する。
「走行記録」は走行記録画面へ遷移する。ホームに「最近の走行」は出さない。

## 3. 走行距離の表示

一覧・サマリーに出す走行距離は、小数第2位まで表示する（例: `10.00km`）。

## 4. 日時の表示

画面に出す日時は共通で `YYYY-MM-DD HH:mm`（24時間・ハイフン）。カレンダー入力はブラウザ表示のスラッシュを許容する。詳細は `docs/02_architecture/date-display.md`。

## 5. 下部固定ボタン

走行記録・パフォーマンス予測・設定では、主要操作と「ホームへ戻る」を画面下部に固定し、スクロールしても押せるようにする。

| 画面 | 固定するボタン |
| --- | --- |
| 走行記録 | 記録を追加 / ホームへ戻る |
| パフォーマンス予測 | 予測する / ホームへ戻る |
| 設定 | 保存 / ホームへ戻る |
| 分析結果 | ホームへ戻る |

「ホームへ戻る」は白抜きの緑色（白背景・緑枠・緑文字）。
下部ボタンは高さを揃え、横幅だけ 3:1 で画面幅いっぱいに並べる。本文も画面幅を使う。
